# W001 J-Link MCP V2 首版实现交接

> V1 规格、架构边界和验收门禁已冻结，本地 main 已重建为干净根提交；下一窗口必须先完成 Phase 0 可行性验证，再按 P1-P4 实现 Rust 产品。

## 目标

在 Windows x64 上实现内部个人使用的 Rust J-Link MCP V2：通过本机 stdio 为 Agent 提供烧录、校验、ELF/DWARF 变量与原始内存读写、核心寄存器、目标控制，以及固定 1-300 秒 HSS 采集和确定性查询；最终以真机和目标 MCP 客户端证据完成验收。

## 当前状态

P001 仍为 in-progress。OpenSpec change define-jlink-mcp-v1 的 proposal、design、tasks 和 9 份 capability spec 已完成；当前没有 Cargo manifest、Rust 源码或已实现功能。main 指向无父根提交 c621728，只跟踪 .gitignore；openspec/、architecture/、AGENTS.md、.agent/、.agents/、.codegraph/ 和 .serena/ 均保留在本机且被忽略。origin 指向 git@github.com:shjqwert/Jlink_MCP_V2.git，远程仓库已确认为空且尚未推送；upstream/main 仅用于参考旧版 HSS 行为。

## 已完成工作

已将最终决策收敛为 6 个封闭领域工具、65 条 Requirement、两个进程和四个 crate 的依赖/状态所有权模型，以及 P0-P4 五阶段任务。独立审查发现的 DLL 配置归属、step 副作用、HSS 规则重复、failed/aborted、短写、overview、MIME、action 集和存储上限等冲突均已修正。Git main 已从旧项目历史原子替换为只含 .gitignore 的干净根提交，本地规格和规则文件重建前后哈希一致。

## 决策与约束

V2 不兼容旧版，使用 Rust，不支持 RTT；首版范围仅 Windows x64、本机 stdio、SEGGER J-Link、ARM Cortex-M、SWD/JTAG。公共接口只能是 jlink_target、jlink_program、jlink_inspect、jlink_write、jlink_control、jlink_hss 及各自封闭 action。所有 DLL 调用由独立 jlink-worker 的唯一 gateway 串行执行；HSS 期间只允许变量和 RAM/MMIO 写入在排空间隙交错，不假设 DLL 并发安全。HSS start 必填 capture_key、duration_s、rate_hz、1-10 个顶层 ELF/DWARF selector 和 return_when；内部自动 Stop 并尾排空。写入/擦除不增加 MCP 授权阻塞，但必须做类型、地址、Flash 边界和实际写入长度校验。OpenSpec、架构、Agent 规则、本机配置和验证原始证据不得提交到 Git。

## 验证

本窗口已观察到 openspec validate define-jlink-mcp-v1 --strict 通过；规格中 65 个 Requirement 与 tasks 中 65 个主要测试映射一一对应，duplicates=0、missing=0。Git 验证显示 main 只有提交 c621728、该提交无 parent 且 tree 仅包含 .gitignore；git status 的可见文件计数为 0。

## 剩余工作

第一步只执行 P0：F0-A 验证旧版行为基线、候选 JLink_x64.dll 的 GetCaps/Start/Read/Stop ABI、帧、timestamp_us、持续/尾部排空、异常、写入交错和 300 秒吞吐；F0-B 验证 Worker 续行、命名管道、探针租约、capture_key 和 partial 恢复；F0-C 验证 DWARF 结构体、数组、位域、union、柔性数组和无损值；F0-D 验证 OpenAI 与 Claude 客户端的 structuredContent、资源、错误、游标和长任务恢复。四包仅在 PASS，或不改变公共合同且已审查记录的 PASS_WITH_LIMIT 时进入 P1。之后严格按 tasks.md 完成 P1 骨架与连接、P2 静态调试、P3 HSS 采集、P4 查询与发布；首次推送只包含可发布代码和配置示例，不强制添加被忽略的本地资料。

## 风险与未知

J-Link 9.70 仍只是候选环境，HSS ABI、结构体、帧格式、时间戳、丢样/溢出和采集中写入影响均未获真机证据；最终 DLL 版本和 SHA-256 尚未冻结。Rust 构建/测试流程尚不存在。目标 OpenAI 和 Claude 客户端兼容性尚未实测。远程仓库仍为空，c621728 只存在本机，首次代码推送前需再次核对 staged 文件不含忽略资料。
