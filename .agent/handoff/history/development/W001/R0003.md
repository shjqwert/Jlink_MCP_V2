# W001 J-Link MCP V2 首版实现交接

> Phase 0 所需用户决策已补齐，V1 客户端范围已收敛为 Windows ChatGPT Desktop；S32K144 板已连接，烧录/控制/写入/300 秒采集、隔离测试模块和 Rust 安装均获授权，但尚未执行 P0。

## 目标

在 Windows x64 上实现内部个人使用的 Rust J-Link MCP V2：通过本机 stdio 为 ChatGPT Desktop 提供烧录、校验、ELF/DWARF 变量与原始内存读写、核心寄存器、目标控制，以及固定 1-300 秒 HSS 采集和确定性查询；最终以真机和目标客户端证据完成验收。

## 当前状态

P001 仍为 in-progress，仓库当前没有 Cargo manifest、Rust 源码或已实现功能。实际主目标已登记为 S32K144、SWD 4000 kHz、IAR 8.32，用户报告板卡已连接。OpenSpec 已将 F0-D 和 P4 客户端验收范围收敛为 Windows ChatGPT Desktop，Claude 和其他客户端不属于 V1 验收范围。J-Link 9.70 为首个候选，6.98a 为同条件比较候选。Rust 安装已获授权但尚未执行；尚未枚举探针、连接目标或运行任何 Phase 0 实验。

## 已完成工作

已完成 6 个封闭领域工具、65 条 Requirement、两个进程和四个 crate 边界以及 P0-P4 五阶段任务的规格化。已只读登记实际 SVN 工程、IAR 工具、ELF/DWARF 输出和两版 JLink_x64.dll 的身份。用户已授权烧录、reset/resume、RAM/MMIO/变量写入、最长 300 秒采集、增加隔离测试专用变量/模块并生成测试固件。已同步 proposal、mcp-contract spec、design、tasks 和 architecture/verification-environment.md，使客户端范围、主目标与授权一致。

## 决策与约束

V2 不兼容旧版，使用 Rust，不支持 RTT；首版范围为 Windows x64、本机 stdio、SEGGER J-Link、ARM Cortex-M、SWD/JTAG。V1 仅要求 Windows ChatGPT Desktop 验收。F0-A 先测 J-Link 9.70，再以相同固件、探针、连接参数、采集计划和证据格式测试 6.98a，不预判最终基线。所有 DLL 调用由独立 jlink-worker 串行执行。用户虽然已授权破坏性真机操作和 Rust 安装，本轮仍明确不启动 W001/P0。SVN 工作副本的既有修改不得恢复或覆盖，IAR 构建必须采用隔离输出。

## 失败尝试

IarBuild 8.2.4 的 -list 返回 Unknown command，未触发构建或修改；IAR .ewp 是 TSD 二进制文件，不能作为 XML 或普通文本解析，后续不重复这两条路径。

## 验证

本轮观察到 openspec validate define-jlink-mcp-v1 --strict 通过，65 条 Requirement 全部仍有 tasks.md 映射。现有 T26_DCU_APP_NXP.out 为 ARM ELF32 little-endian EABI5，包含 DWARF v4，producer 为 IAR 8.32.3.193；具体产物和 DLL SHA-256 已记录在 architecture/verification-environment.md。本轮未枚举探针、未由工具连接目标、未烧录、未写入、未复位、未运行 HSS、未安装 Rust。

## 剩余工作

用户明确要求开始 W001 后，先只读枚举探针型号/序列号、目标供电和连接状态并登记证据指纹；再建立 Requirement→主要测试→证据矩阵，安装并冻结 Windows MSVC Rust stable 版本，按 F0-A 至 F0-D 执行 Phase 0。若需生成测试固件，先自动识别 IAR 活动 configuration 并设计不覆盖现有输出及用户修改的隔离构建路径。发布前补齐 JTAG smoke 硬件证据。四个门禁未全部 PASS，或未取得不改变公共合同且经审查的 PASS_WITH_LIMIT 前，不进入 P1。

## 风险与未知

实际探针型号/序列号和工具读取到的目标状态仍待 P0 开始时登记。IAR 活动 configuration 尚未取得，原地 build 可能覆盖用户产物。当前只确认 SWD，JTAG 最终发布证据仍缺。两版 DLL 的 HSS ABI、帧、时间戳、丢样/溢出、300 秒吞吐、恢复和写入交错影响均尚无本轮真机证据。

## 证据

本地环境与授权见 architecture/verification-environment.md；规格入口为 openspec/changes/define-jlink-mcp-v1/proposal.md、design.md、specs/mcp-contract/spec.md 和 tasks.md；最终产品决策见 architecture/decision-review-q01-q67.md，接口合同见 architecture/data-contract/mcp-interface-v1.md。实际 IAR 输出与两版 JLink_x64.dll 的路径、大小和 SHA-256 均已在环境记录中冻结。
